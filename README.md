# 連江縣老宅延壽機能復新計畫 - 3D 政策微縮群島互動展廳

本專案為連江縣「115-116 年度老宅延壽機能復新計畫」政策可視化 3D 互動展廳，採用 WebGL / Three.js 打造微縮模型風格（Tilt-shift 模型玩具城市），整合政策合規法規、40 種情境即時試算、32 家初評機構檢索、50 題 QA 手冊全文索引、6 大申請表單下載與舊有房屋證明地政登記流程大圖。

支援桌面瀏覽器、手機與平板等行動裝置直開瀏覽。

---

## 🏛️ 系統亮點與功能結構

1. **四鄉五島專屬特色主視覺（Pointy-top 黏土六角島）**：
   - **南竿島**：媽祖巨神像地標立柱、福澳港腹地意象與示範連棟公寓群。
   - **北竿島**：芹壁石屋聚落，具備人字砌、丁字砌岩石色澤與紅色馬鞍形封火山牆。
   - **東引島**：高聳歐風東引島燈塔（360度旋轉探照金光）、國之北疆峭壁與防風管線固定意象。
   - **莒光島（東西莒）**：東莒燈塔與大埔聚落，突出銀髮友善在宅安心養老無障礙設施與緩坡扶手。
   - **動態海浪與航運**：多重正弦波反光動態海面，穿梭「臺馬之星」客輪、馬祖傳統雙帆木造漁船與巡防快艇。
   - **三大晨昏光影切換**：晨曦暖陽、暮色夕照、藍調夜景（燈塔光錐增強、老宅窗戶點亮暖黃夜燈）。

2. **115 年度老宅延壽 40 種情境即時試算矩陣**：
   - 完整收錄官方情境手冊之「公寓類 20 組（公-01 ～ 公-20）」與「透天住宅類 20 組（透-01 ～ 透-20）」。
   - 一鍵切換情境快速載入，並支援自訂報價與面積試算。
   - 核心裁決邏輯遵循：`Min(工程報價 × 65%, 施作面積 × 3,500元, 法定天花板)` 取最小額度。
   - 弱勢與銀髮族加碼：一般上限 20 萬元，含長者或弱勢身分加碼至 30 萬元。

3. **國土管理署 32 家初評機構即時檢索**：
   - 完整收錄共同供應契約 32 家專業初評機構（機構名稱、負責人、地址、服務電話）。
   - 支援即時關鍵字搜尋與篩選。

4. **政策影音與公版簡報線上點看**：
   - 內建政策宣導影片播放器（支援「一般宣導版」與「資深長者解說版」切換）。
   - 提供 115 年度官方公版宣傳簡報（PPTX）一鍵下載。

5. **QA 手冊 50 題全文手風琴索引**：
   - 收錄「老宅延壽宣傳手冊」完整 50 題 QA：
     - A. 計畫概要篇（15 題）
     - B. 建築法令篇（15 題）
     - C. 經費補助篇（15 題）
     - D. 申辦流程篇（5 題）
   - 支援即時關鍵字檢索與分類快速切換。

6. **6 大官方申請表單下載**：
   - 修繕需求申請表（透天住宅類、公寓類）
   - 申請補助計畫書（透天住宅類、公寓類）
   - 申請補助自我評估表（透天住宅類、公寓類）

7. **舊有房屋證明 ＋ 地政測量及登記流程圖**：
   - 高解析度完整流程指引大圖。
   - 五大申辦核心步驟說明。

## 📱 行動端與瀏覽器支援

- 採用原生 ES Modules 與 Three.js 0.160.0，免本機打包工具，隨開即用。
- 支援 iOS / Android 手機、平板與 PC 桌面端觸控縮放、旋轉與點擊互動。
- 專區諮詢窗口：連江縣政府工務處 ＆ 福建金門馬祖地區建築師公會駐府服務台（0836-25330 #6338）。
