## 🔍 兩大版本核心介面差異性對比

| 比較項目 | 介面一：原始六角群島航線版 (V1) | 介面二：3F微縮模型城市深度版 (V2) |
| :--- | :--- | :--- |
| **地形設計** | 象徵性純幾何白色六角稜柱（Hexagonal Prisms） | 自然起伏花崗岩斷崖、階梯梯田與山陵綠坡高低差 |
| **海洋與航線** | 平面漸層海水 ＋ 虛線航海連線 | 動態正弦頂點波浪（Vertex Waves） ＋ 巡弋客輪動態航行 |
| **建築語彙** | 示意性立方體方塊與階梯幾何 | 芹壁閩東石屋（人字砌/丁字砌/壓瓦石）、馬鞍牆、透天無障礙坡道、公寓外掛電梯 |
| **情境試算** | 基礎三取小計算機 | 內建 **40 組官方情境矩陣速查（公-01～20、透-01～20）**，支援「一鍵代入試算」 |
| **政策問答** | 精選分類 QA | **50 題官方手冊全題庫**，支援關鍵字即時模糊檢索與手風琴摺疊 |
| **機構清單** | 32 家文字列表 | 32 家機構獨立卡片、關鍵字篩選、手機**點擊直接撥號（tel:）** |
| **檔案資料下載** | 線上展示為主 | 獨立目錄（`data/`, `docs/`, `forms/`, `presentation/`），可**單獨下載 Word、PDF、JSON** |
| **環境音效** | 無 | 內建純 Web Audio API 合成之自然海潮與海風白噪音音效 |
